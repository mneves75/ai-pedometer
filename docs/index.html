Privacy by boundary

Your health context is not cloud-AI input.

AIPedometer reads only the HealthKit data you authorize. AI inference and the activity context used for it stay on-device. Purchase services receive the transaction and entitlement data needed to manage Premium access—not your workout narrative.

Read the privacy policy → Read the security model ↗
  • ✓ No account or sign-in required
  • ✓ HealthKit access remains permission-based
  • ✓ No health context sent to a cloud AI service
  • ✓ Sensitive log values are redacted
  • ✓ Unverified Premium configuration fails closed
