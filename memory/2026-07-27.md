### THE BIG ONE — CI had been dead for a week and I had not noticed

- `DX-01 (HIGH)`: **CI failing on every run since 2026-07-20**, 14 red runs.
  Root cause: `Scripts/check-agents-sync.sh` requires `~/dev/GUIDELINES-REF/AGENTS.md`,
  a **maintainer-only local path that cannot exist on a GitHub runner**. CI is one serial
  job with that guardrail first, so it blocked **every build and test step**.
- **This means every commit I pushed on 2026-07-24/25 had zero CI verification.** I pushed
  six times and never ran `gh run list`. Local E2E was green, so I assumed CI was too.
- Fix: absence of the reference is now a **skip** (still strict where the reference exists;
  `REQUIRE_GUIDELINES_REF=1` restores fatal). Verified all three modes explicitly.
- **RULE: after any push, run `gh run list` before claiming a cycle is verified.
  Local green ≠ CI green.**

### Highest USER impact — 11 strings shipped untranslated on the revenue surface

- Audit claimed 5 paywall strings missing from the catalog; scanning myself found **11**
  (5 paywall + 6 AI insight fallbacks).
- Mechanism: `String(localized:)` returns the KEY when no catalog entry exists → pt-BR
  devices saw **English on the subscription paywall**. Violates the pt-BR contract.
- The localization suite could not catch it: ~35 assertions were `#expect(!localized.isEmpty)`,
  which is true for the returned key → **structurally incapable of failing**.
- Fixed: added all 11 with pt-BR translations + replaced the tautological tests with a
  **source-scanning test** that walks every `L10n.localized(...)` / `String(localized:)`
  literal and requires a catalog entry.
- **Two existing tests then failed — because the fix was correct.** `InsightServiceTests`
  asserted the English fragments `"safe summary"` / `"next week"`, which only passed
  *because the strings were untranslated*. The suite had encoded the bug as expected
  behavior. Fixed by asserting through `String(localized:)` (the same lookup production
  uses), so they verify the fallback path, not the language. Made `recommendation` stricter
  (`==` not `contains`).

### Other fixes

- **Live Activity orphaned** after force-quit/crash: `end()` guarded on an in-memory id →
  unconditional no-op after relaunch; the activity stayed pinned to the Lock Screen with
  frozen metrics through both Finish and Discard, and a new workout stacked a second one.
  Now enumerates activities, sweeps at launch, and publishes a real `staleDate`.
- **Widgets showed yesterday as today**: no staleness gate on the app-group payload.
  Now resets day-scoped values at the day boundary + adds a midnight timeline entry.
  **Deliberately narrower than `isStale`**, which is also true for same-day data >1h old —
  zeroing that would erase real steps. Logic moved to `Shared/` so it is unit-testable
  (widget sources are in no test target — that is finding TEST-03, left open).
- **Premium enforcement race** (found independently by BOTH Codex reviews): enforcement
  sampled cached CustomerInfo; the verified revocation arriving later via the stream never
  re-triggered it. Now notifies from `publishCustomerInfo`, the single choke point all
  sources route through. Failed verification deliberately does NOT notify (indeterminate).
  Single-flight because resume regenerates content on-device.
- Security lows: Release honored `XCODE_RUNNING_FOR_PREVIEWS` (now DEBUG-only, matching the
  `LaunchConfiguration.isOverridable` lockdown); GPX size cap guarded a `stat` not the read
  (now bounded `FileHandle`); `.p8`/provisioning/`.p12` now gitignored (Gitleaks: history
  clean across 188 commits, so this is prevention).

### MY MISTAKES THIS CYCLE

1. **Rewrote `Localizable.xcstrings` with `json.dump` → reformatted all 5471 lines.**
   Xcode writes `"key" : {` (space before colon) and uses its own collation, not ASCII sort.
   Semantically identical (verified 0 removed / 0 modified / 11 added) but an unreviewable
   diff. Fixed by reloading the pristine file with `object_pairs_hook=OrderedDict`, appending
   only new keys, and dumping with `separators=(",", " : ")` → **187 insertions, 0 deletions**.
   **RULE: never wholesale-rewrite a generated/tool-owned file; preserve original order and
   formatting, then verify the diff is purely additive.**
2. **Edited inside the `## GUIDELINES-REF` mirrored section of AGENTS.md** (line 378, section
   starts at 269) to fix dangling `docs/agents/*.md` links → broke `check-agents-sync.sh`.
   That section is a **mirror of upstream `~/dev/GUIDELINES-REF/AGENTS.md`** and must stay
   faithful; the dangling links are an upstream artifact and belong upstream. Reverted.
   **RULE: before editing AGENTS.md, check whether the line is above or below `## GUIDELINES-REF`.**
3. Left a compiled Mach-O `main` binary in the repo root (an audit subagent ran
   `swiftc -O` micro-benchmarks; `swiftc` defaults its output to `main`). Removed.
4. A test fixture used `1_700_000_000` (22:13 UTC) and added 3h expecting "same day" — it
   crossed midnight. Production was right, my fixture was wrong. Now anchored to an explicit
   start-of-day constant.
