# 2026-11-24 — Liquid Glass Redesign & Repository Hardening

Branch: `feat/liquid-glass-redesign-and-hardening` (base `3323481`, Xcode 27.2 `27B52`, simulator `iPhone 17 Pro` iOS 27.3).

## Key changes

- **iOS 26+ Liquid Glass UI/UX Redesign**: Redesigned Dashboard, History, Workouts, Active Workout, AI Coach, Badges, Onboarding, More, Settings (+ `GoalEditorSheet`), About, Training Plans, and Health Access Help around a calm-content + floating-Liquid-Glass hierarchy (`calmCard`, `glassCapsuleSurface`, `glassSecondaryButton`, `AmbientZenithBackground`, native floating TabBar with `.tabBarMinimizeBehavior(.onScrollDown)`). Fixed invisible `"sparkles.slash"` SF Symbol in `AIUnavailableStateView`, user chat bubble contrast (`onAccent`), Tip Jar price contrast, `HealthAccessHelpSheet` card padding, and Light/Dark WCAG contrast on ring percentage and goal subtitles.
- **Core, AI, HealthKit, Watch & Security Hardening**:
  - `AIChatLinkPolicy`: blocked `*.localhost` and mixed-radix IPv4 (`inet_aton`).
  - `LocalMarkdownSupport`: narrowed HTML sanitizer regex so `< 5,000 and > 2,000` prose is preserved.
  - `GPXRouteParser`: clamped haversine `a` in `0...1` (antipodal NaN fix) and ignored empty `<metadata><name>`.
  - `SharedStepData` & `WatchPayload`: shifted `weeklySteps` across midnight rollovers.
  - `HealthKitService` / `HealthKitSyncService` / `DailyStepCalculator`: DST-safe `startOfDay(for: nextDay)` stepping, `builder.discardWorkout()` on export failure, clamped workout end times, finite/non-negative sample sanitization.
  - `HealthKitServiceFallback`: stopped latching `.authorizationFailed` and one-way `useFakeDataFallback`.
  - `BackgroundTaskService`: `nonisolated static func makeExpirationHandler` + `OSAllocatedUnfairLock`-backed `TaskCompletionGate`.
  - `WorkoutSessionController`: retry recoverable lookup, clamp pause/end bounds, rollback all 4 `healthKitExport*` fields on save error, guard state after `await refreshMetrics()` before starting polling loop.
  - `TrainingPlanService`, `GoalService`, `StepTrackingService`, `MotionService`, `TipJarStore`, `InsightService`, `StreakDataTool`, `WorkoutLiveActivityWidget`: cancellation checks, positive goal guard, sync-off streak reset, retained `CMPedometer`, live `canMakePayments`, pluralized streak tool output, `Formatters` calories/steps formatting.
  - SwiftUI/Swift 6.2 skill polish: `Equatable` on `@Observable` element types (`DailyStepSummary`, `ChatMessage`, `AIServiceError`, `WeeklyTarget`), stable `ForEach` identity (`\.element.weekNumber`), direct `.enumerated()`, `@Bindable` replacing closure `Binding`.
- **Preventive Gates & Supply Chain**:
  - Added `ast-grep` rules + tests `swift-no-raw-string-localized` and `swift-no-numeric-formatted`; widened `swift-ai-views-no-environment-openurl` to `AIPedometer/Features/AICoach/**`.
  - Removed unused `wrangler` devDependency (`pnpm audit --audit-level moderate`: 9 vulnerabilities -> 0).
  - Hardened `.github/workflows/pages.yml` with explicit allowlist staging into `${RUNNER_TEMP}/pages-site` and `.md` guard.
  - Removed hardcoded local paths from `brag-output/work/render.mjs` and `audio.mjs`; fixed bash 3.2 empty-array guard in `Scripts/lib/xcode-toolchain.sh`; aligned `Scripts/preflight.sh` `ast-grep` flags; excluded special hardware runtimes in `Scripts/e2e-simulator.sh`.
- **Test Suite**: Added focused regressions for every hardened boundary and pruned 20 redundant/compiler-guaranteed tests (682 -> 663).
